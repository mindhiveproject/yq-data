Reproduce

Everything on this page is generated from the test run: a figure appears when a test declares it with rec.compare(...) (see harness.ts), and every error figure is computed from the plotted series. Methods and references are in tests/unit/golden/README.md.

npm run golden:report                          # run the suite, then rebuild report/index.html
npx jest tests/unit/golden                     # green; divergences are expected failures
GOLDEN_STRICT=1 npx jest tests/unit/golden     # print each measured gap
