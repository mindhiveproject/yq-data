yq-data Golden Values

The package's signal processing, checked against SciPy, YASA and NeuroKit2 and against synthetic signals with known ground truth. Most of it matches to float precision. This page charts the five divergences that change the numbers most.

D1 · Filter design

Band filters are not Butterworth

Low-pass and high-pass match scipy.signal.butter to 1e-15. Band-pass and band-stop are built from identical RBJ biquads at the centre frequency, so the cutoffs sit near −6 dB instead of −3 dB and the passband sags. Package order 4 is compared with butter(2, band), which has the same pole count.

D6 · Zero-phase filtering

filtfilt edges start from zero

Synthetic Muse PPG on a raw-sensor offset of 1.2×10⁵ counts, 3 Hz low-pass, zero-phase. SciPy seeds each pass with the steady-state response, while the package starts from a zero state. The interior agrees to about 1e-6. At the ends the package is off by up to 8,265 counts against a pulse peak-to-peak of 912.

Package filtfiltscipy.signal.filtfilt
D2 · BandPower

Default relative band power is not a share of power

Synthetic 4-channel Muse EEG, 4 s window, averaged across channels. The defaults average spectral amplitude, so relative: true gives each band's share of mean amplitude. Switching to scaling: "psd" with aggregate: "sum" lands within 0.03 of YASA.

D7 · HeartRate

Edge false beats inflate HRV

SDNN per 10 s window, from the HeartRate node and from the true beat locations of each synthetic signal. Each false beat sits within 0.1 s of a window boundary. The median-based rate absorbs it and stays within 1.5 bpm. SDNN and RMSSD take every interval as given, with no normal-to-normal cleaning.

D9 · Windowing

Windowing falls behind real time

Muse sends 12 EEG samples per packet. A 2 s window with a 0.04 s hop (10 samples) has more than one new frame per packet, but the node emits one window per packet, so the surplus queues up. The line replays that rule for a minute of streaming. In the test, 30 s of data produced .

Reproduce

The full list of divergences, with suggested directions, is under Open Gaps in the package spec. Methods and references are in tests/unit/golden/README.md.

npx jest tests/unit/golden                     # green; divergences are expected failures
GOLDEN_STRICT=1 npx jest tests/unit/golden     # print each measured gap
GOLDEN_REPORT=1 npx jest tests/unit/golden && python tests/unit/golden/report.py
